**ツールの正体**

`ラシード/combo.html` は、依存ライブラリなしの単一HTMLアプリです。レシピデータをHTML内の JSON に埋め込み、File System Access API で **HTML自身を上書き保存する自己書換方式** をとっています。動画は隣の `clips/` を相対参照し、配布時だけ base64 で埋め込む2モード構成です。

**主な機能（仕様書の3章）**

- 閲覧: カード表示、クリック再生、1/20秒単位のコマ送り、レシピ表記の自動色分け（SA・PC/DI・DR・必殺技コマンドを判別）
- フィルタ4軸（位置・タグ・SA・習得）とソート4種（記述順・ダメージ・Dゲージ・効率）
- 習得済みトグル。localStorage と HTML 内フラグの二重保存
- 編集モード: 追加・編集・削除・複製・並べ替え、動画のドロップで `clips/` に実ファイル書き込み
- 保存・配布用HTML書き出し・JSON入出力
- 外部の compress.bat で fps20・CRF30 に軽量化

**ブラッシュアップ候補として見つかった問題（6章に17項目）**

主なものを挙げます。

1. 起動直後、閲覧モードなのに「編集を終える」ボタンが点灯したまま。保存処理がボタン状態を戻していないバグです

4. 習得状況は localStorage 優先で、別PCや別ブラウザでは HTML 内の値が無視されます
5. 全文検索、Undo、フレーム有利や対キャラ情報の構造化がありません。メモに「+5F」「春麗/ブランカ限定」が散在しています
