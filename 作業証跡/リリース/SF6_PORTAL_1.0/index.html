参考情報を追加

使い方
  1. 新しいキャラは COMBO_DB/テンプレート/ をコピーして COMBO_DB/<キャラ名>/ に置く（相手キャラの対策は VS_DB/テンプレート/ をコピーして VS_DB/<相手キャラ名>/ に置く）
  2. コピーした combo.html を開き、「編集」→ キャラ名を入力 → 「HTMLを保存」
  3. このポータルで「編集」→「キャラを追加」。キャラ名は combo.html と同じにする。自分が使うキャラは「自キャラ」にチェック
  4. カードの画像は 画像/<キャラ名>/ に置き、キャラの編集フォーム「画像を選ぶ」でそのファイルを選ぶ（編集モードでカードにドロップしてもよい）。カード全面に敷かれるので横長のキーアートが向く
  5. 解説動画などは「参考」ボタン → 「追加」。概要と URL を書く
  6. 背景画像は「背景画像: 画像を選ぶ」で設定する。初回だけ スト６/画像 フォルダを選び、続けてその中のファイルを選ぶ（サブフォルダはどれでもよい）。パス欄に 画像/… を直接入力してもよい
  7. 変更したら「HTMLを保存」で index.html を上書きする

背景画像の選び方（ポータル）

  • 全キャラの入口なので、特定キャラよりシリーズのキービジュアルや集合絵が向く。置き場所は 画像/StreetFighter6/ のような共通フォルダ
  • カードが多く並ぶ画面なので、背景は主張しすぎないものを。カードの画像（キャラごと）と背景（全体）は役割が違う
  • 大きさ: 横長（16:9 前後）で、幅 1920px 以上が目安（最低でも画面幅の 1280px）。画面いっぱいに拡大して敷かれるため、小さい画像はぼやける
  • 明るさ: 明るめで淡い画像が向く。紙色の上に「乗算」で重ねるので、白い部分は紙色のまま、暗い部分だけが沈む。暗い画像は 45% でも重く見えるので濃さを下げる
  • 構図: 被写体（キャラ）が中央〜右にある画像。左上に見出し、左側にカードや動画が並ぶので、左に顔があると隠れる
  • 避けるもの: 文字やロゴが大きく入った画像（見出しと重なる）、細かい模様（グレースケールにすると濁る）、縦長の画像（左右が切れる）
  • 濃さ: 色ありなら 30〜45%、グレースケールなら 20〜35% が目安。カードの上の文字は影響を受けないので、雰囲気と背景の見やすさで決める
  • 形式: JPG（写真・アート）か PNG。1枚 2MB 以内にしておくと開くのが速い

カードの画像の選び方: カード全面に敷かれるので、横長のキーアートが向く（白背景の小さな立ち絵は粗く見える）。顔が右寄りにあると、左上の統計や右下の名前と重ならない。置き場所は 画像/<キャラ名>/

動画の軽量化に使う ffmpeg.exe は スト６/ 直下に1つ置く。対応ブラウザは Chrome / Edge。
