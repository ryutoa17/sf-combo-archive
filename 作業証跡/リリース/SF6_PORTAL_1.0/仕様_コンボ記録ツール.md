## 1. 概要

キャラクターごとに1つの HTML ファイルでコンボ・セットプレイのレシピを管理する、**完全ローカル動作の単一ファイルアプリ**。

- サーバー不要。ダブルクリックで `file://` として開く
- 依存ライブラリなし（Vanilla JS / CSS のみ、外部通信ゼロ）
- データは HTML 内の `<script type="application/json" id="combo-data">` に埋め込み、**HTML 自身を書き換えて保存**する自己書換方式
- 動画は隣の `clips/` フォルダに置き、相対パスで再生

## 2. データモデル

レシピ1件 = JSON オブジェクト。配列として保持される。

| フィールド | 型 | 必須 | 意味 |
|---|---|---|---|
| `file` | string | ○ | クリップ名（拡張子なし）。**主キー扱い**（習得状況の紐付けにも使用） |
| `src` | string | | 実ファイル名。`file + ".mp4"` と異なる場合のみ保持 |
| `recipe` | string | | レシピ表記。半角スペース区切りでトークン化される |
| `damage` | number | | ダメージ。0 は「—」表示 |
| `drive` | number 0〜6 | | Dゲージ消費本数 |
| `sa` | number 0〜3 | | 使用 SA。0 = なし |
| `tags` | string[] | | 固定5種から複数選択 |
| `position` | "中央" / "端" | | 画面位置 |
| `note` | string | | メモ（改行可） |
| `learned` | true | | 習得済みフラグ（未習得時はキー自体を削除） |
| `fav` | true | | お気に入りフラグ（テンプレート版のみ。未設定時はキー自体を削除） |
| `created` | "YYYY-MM-DD" | | 作成日（テンプレート版のみ。フォーム保存・複製時に自動付与） |
| `updated` | "YYYY-MM-DD" | | 更新日（テンプレート版のみ。フォーム保存のたびに更新。カードのメタ行に表示。ポータルが最終更新日の集計に使う） |
| `data` | data URI | | 配布用 HTML でのみ存在。base64 埋め込み動画 |

固定タグ: `コンボ` / `パニカン` / `インパクトパニカン` / `壁インパクト` / `セットプレイ`

現在のデータ: 10件（壁インパクト 2、セットプレイ 8、コンボ 1 ※重複あり）

## 3. 機能一覧

### 3.1 閲覧モード（デフォルト）

**カード表示**（1レシピ = 1カード、左に動画・右に情報の2カラム、820px 以下で1カラム）

- 動画: `preload=metadata`（原本は `none`、6章 #3）/ ループ / ミュート。クリックで再生・停止
- コマ送り: ◀ ▶ ボタン、または動画フォーカス中に ← → キー。**1フレーム = 1/20秒固定**
- 頭出しボタン、現在時刻表示（秒、小数2桁）
- タグチップ（種類ごとに色分け）、お気に入り ☆/★ トグル（テンプレート版のみ）、習得済みトグル
- レシピ表記の自動色分け（後述）
- ダメージ / Dゲージ（6マスのゲージ表示）/ SA
- メモ、位置、クリップ名、更新日（テンプレート版のみ）
- 習得済みカードは不透明度 62% に落とし、ホバーで戻る
- クリップが無い場合は「クリップ未配置 clips/xxx.mp4」プレースホルダ

**レシピ表記の色分け**（`classify()`）

| トークン | 色 | 判定 |
|---|---|---|
| SA1/SA2/SA3/CA、236236 系コマンド | 紫 (`--sa`) | 正規表現 |
| PC / CH / DI | 橙 (`--punish`) | 完全一致 |
| DR / DRC | 水色 (`--rush`) | 完全一致 |
| 236/214/623/421/41236/63214/22 で始まる | 赤 (`--special`) | 正規表現（`[2]8` 等のタメ表記も許容） |
| `>` `,` `~` `()` `[]` `+` | 灰 (`--sep`) | 区切り記号 |
| その他（5MP、中足、弱ミキサー 等） | 白 (`--normal`) | デフォルト |

**フィルタ**（画面上部に sticky 固定、各軸は単一選択で AND 結合）

- 位置: すべて / 中央 / 端
- タグ: すべて / 5種
- SA: すべて / なし / SA1 / SA2 / SA3
- 習得: すべて / 習得済み / 未習得
- お気に入り: すべて / ★ お気に入りのみ（テンプレート版のみ）

**並び順**（同じ項目を再クリックで昇降反転）

- 記述順（手動順）
- ダメージ（降順）
- Dゲージ（昇順）
- 効率 = ダメージ ÷ Dゲージ（ゲージ0は 0.5 で割る）

件数表示: 「表示 / 全件」+ 「習得 n / 全件」

### 3.2 習得状況・お気に入りの管理

- カードの「未習得 / ✓ 習得済み」ボタン、「☆ / ★」ボタンで切替
- **保存先は2箇所**: `localStorage`（キー: `combo_learned:<キャラ名>` / `combo_fav:<キャラ名>`、即時）と HTML 内 JSON の `learned` / `fav` フラグ（HTML保存時）
- 起動時: localStorage があればそれを優先、無ければ HTML 内の値を種にする。JSON 読み込み時も同じ手順で再読込
- 配布用 HTML 書き出し時は `learned` / `fav` を除去（個人の状態なので配布しない）
- テンプレート版では両者を `loadFlag()` / `saveFlag()` で共通化している

### 3.3 編集モード（ヘッダの「編集」ボタンで切替）

編集バーとカード下の行ツールが表示される。

**キャラ名**（テンプレート版のみ）

- 編集バー先頭のテキスト欄で変更。見出し `<h1>`、`<title>`、習得状況の localStorage キーに反映
- 変更は「HTMLを保存」で HTML に書き戻される
- ポータルの習得数・お気に入り数はこのキャラ名をキーに localStorage を読むので、**ポータルに登録するキャラ名と一致させる**

**ポータルへ戻るリンク**（テンプレート版のみ）: ヘッダ左上の「← 一覧」が `../../index.html` を開く

**レシピ追加 / 編集フォーム**

- 入力: クリップ名、位置、レシピ、ダメージ、Dゲージ、SA、タグ（チェックボックス）、メモ
- 動画ドロップ領域（ドロップ or クリックで選択）。クリップ名が空なら動画ファイル名から自動入力
- フォルダ接続時のみ「接続フォルダ内の動画から選ぶ」セレクトが出現
- 保存 / 取消 / このレシピを削除（確認ダイアログあり）

**行ツール**

- 編集 / ↑ ↓（記述順のときのみ）/ 複製

**カードへの直接ドロップ**: 編集中は動画枠に mp4 をドロップして紐付け可能

### 3.4 作業フォルダ接続（File System Access API）

- `showDirectoryPicker({mode:"readwrite"})` で `combo.html` のあるフォルダ、または `clips` フォルダを選ぶ
- `.html` を含むフォルダなら「ルート」と判定し、`clips/` を自動作成して掘る
- 接続後: フォルダ内の mp4/webm/mov/m4v を走査し、各レシピの動画を `blob:` URL に解決して再生
- 動画ドロップ時は `clips/<file>.mp4` として **実ファイルを書き込む**（同名があれば上書き確認）
- ファイル名照合は大文字小文字を無視
- `clips` 以外の名前のフォルダを接続すると警告表示
- 非対応ブラウザ（Firefox / Safari）ではメッセージのみ
- 未接続で動画をドロップした場合はその場限りのプレビュー

### 3.5 保存・書き出し

| ボタン | 動作 |
|---|---|
| HTMLを保存 | 現在の DOM を複製 → JSON を差し替え → 表示状態をリセット → `showSaveFilePicker` で `combo.html` に上書き。非対応時はダウンロード |
| 配布用HTMLを書き出す | 接続フォルダの動画を全て base64 で `data` に埋め込み `combo_share.html` として保存。**1ファイルで再生可能**。推定サイズ（×1.34）が 200MB 超なら確認。動画が見つからないレシピは名前を報告 |
| JSON書き出し | `combos.json` をダウンロード（バックアップ用） |
| JSON読み込み | 配列 JSON を読み込んで全置換 |

- 未保存変更があると status に「未保存の変更があります」、ページ離脱時に `beforeunload` 警告
- 配布用 HTML を開いた状態で「HTMLを保存」すると動画が外れる旨の確認あり
- 配布用 HTML は起動時に `hydrate()` で base64 → Blob に展開し、メモリ上の文字列を解放

### 3.6 動画軽量化（compress.bat、外部ツール）

- 使い方: 編集済み動画を bat にドラッグ&ドロップ（複数可）→ `clips/` に同名 mp4 を出力
- 設定（固定）: 音声削除、**fps=20**、libx264 CRF 30、preset slower、GOP 600、yuv420p、faststart
- 解像度・切り抜きは変更なし
- 結果として 1本あたり 1〜4MB 程度
- ffmpeg.exe は同フォルダ → 1つ上 → 2つ上（`スト６/ffmpeg.exe`、標準）→ PATH の順に探す

## 4. 動作要件・前提

| 項目 | 要件 |
|---|---|
| ブラウザ | Chrome / Edge 推奨（File System Access API 必須）。他ブラウザは閲覧のみ |
| 実行環境 | `file://` で開く前提。サーバー不要、ネット不要 |
| 動画形式 | H.264 mp4（yuv420p）。20fps でエンコードされていることをコマ送りが前提にしている |
| 動画配置 | `combo.html` と同階層の `clips/` フォルダ |
| 保存 | HTML 自身を上書き。Git 等の外部バージョン管理は無し（JSON 書き出しで代用） |
| ツール識別 | テンプレート版は `<meta name="sf6-tool" content="combo">` と `<meta name="sf6-tool-version" content="2">` を持つ。ポータルが種別とバージョンの判定に使う |
| 1キャラ1ファイル | 別キャラは `テンプレート/` をコピーして作る。キャラ名は編集バーから設定（原本のラシード版は `<h1>` にハードコード） |
| フォント | Hiragino / Yu Gothic / Noto Sans JP のシステムフォント。ダークテーマ固定 |
| アクセシビリティ | `aria-pressed` / `aria-label` / `focus-visible` 対応、`prefers-reduced-motion` 対応 |

## 5. 設計上の特徴

- **自己書換 HTML**: アプリとデータを1ファイルに同居させ、配布・バックアップ・移動が容易
- **動画は外部参照 or 埋め込みの2モード**: 作業用は `clips/` 参照で軽く、配布用は埋め込みで自己完結
- **主キー = クリップ名**: レシピと動画とローカル習得状況をすべて `file` で結ぶ
- **ランタイム状態とデータの分離**: `srcMap`（blob URL）、`dirFiles`（ハンドル）、`learned`（Set）は保存対象外
- **フィルタ・ソートは宣言的定義**: `AXES` / `SORTS` 配列に追加すれば UI に反映される構造

## 6. 解析中に見つかった問題点・不整合

ブラッシュアップの候補として列挙します（重要度順ではなく発見順）。

### バグ・不整合（テンプレート版で修正済み。ラシード原本は未修正）

| # | 内容 | テンプレートでの修正 |
|---|---|---|
| 1 | **初期表示で「編集を終える」ボタンが点灯している** — `buildHtml()` が `body.editing` は消すが `#editToggle` のテキストと `on` クラスを戻していない（[combo.html:231](COMBO_DB/RASHID/combo.html#L231) / [combo.html:1001-1017](COMBO_DB/RASHID/combo.html#L1001-L1017)） | 初期 HTML を「編集」に戻し、`buildHtml()` でもボタンをリセット |
| 2 | **compress.bat のヘッダコメントが実設定と食い違う** — コメントは fps 10、実際は `FPS=20` | コメントを 20 に修正。HTML の `FPS` と揃える旨を追記。ffmpeg.exe を親フォルダからも探すよう変更 |
| 3 | **クリップ未配置プレースホルダが出ない** — `preload="none"` のため存在しないファイルでも `error` が発火しない。headless Chrome で再現確認済み | `preload="metadata"` に変更。存在しないクリップで「クリップ未配置」が出ることを確認 |
| 4 | **クリップ名の大文字小文字ゆれ** — データ上 `+5f`、実ファイルは `+5F`。他 OS の `file://` 参照では失敗する | フォーム保存時、接続フォルダに大小違いのファイルがあれば実ファイル名を `src` に記録 |
| 5 | **タグ定義が2箇所** — HTML の `#f_tags` ベタ書きを JS が上書きしている | HTML 側を空にし、`TAG_ORDER` / `TAG_COLOR` を唯一の定義にした |
| 6 | `openForm()` 内で `#f_pick` を設定 → `fillPicker()` で作り直し → 再設定（冗長） | `fillPicker()` の後に1回だけ設定 |
| 7 | **（修正中に発見）未配置プレースホルダへのドロップで `attachVideo()` が2回走る** — `.missing` と親 `.clip` の両方に drop ハンドラがあり、イベントがバブルする。2回目は「既にあります。上書きしますか？」の確認が出る | drop ハンドラで `stopPropagation()` |

ラシード原本のデータ側の不整合（#4 の `+5f`）はデータ修正が必要。テンプレートに移行する際に直す。

### 設計上の弱点（未着手）

8. **クリップ名の変更で習得状況が消える / 複製で共有される** — `learned` が `file` をキーにしているため
9. **習得状況が localStorage 優先** — 別 PC・別ブラウザで開くと HTML 内の `learned` が無視される。逆に localStorage が残っていると HTML を差し替えても古い状態が出る
10. **コマ送りの 1/20 秒固定** — compress.bat を通さない 60fps 動画では 3フレーム単位で進む。動画の実 fps を検出していない
11. **レシピの削除で動画ファイルは残る** — `clips/` に孤児ファイルが溜まる
12. **全文検索がない** — レシピ・メモの文字列で絞り込めない（「シミー」「無敵」などで探せない）
13. **Undo なし** — 削除・並べ替え・JSON読み込みは即時反映。JSON 読み込みは全置換で確認ダイアログもない
14. **日本語技名は色分けされない** — `弱ミキサー` `中スパイク` `前ステ` などは全て白。強度（弱/中/強）や技種別の色分けは未対応
15. **キャラ横断ができない** — 1キャラ1HTML。タグ・色定義・UI を変えると全キャラ分の HTML を更新する必要がある。テンプレートを更新しても既存キャラの HTML には反映されない（データ部分を JSON 書き出し → 新テンプレートに読み込みで移行する運用）
16. **相手キャラ限定情報の構造化なし** — 「春麗/ブランカ/DJ 等」のような対キャラ情報はメモの自由文のみ
17. **フレーム有利情報の構造化なし** — 「+5F」「+52F」はクリップ名やメモに散在。フィルタ・ソート対象にできない
18. **配布用 HTML は動画を全て base64 化するため、動画合計の約 1.34 倍のサイズになる**。10本で約 30MB 程度と推定

## 7. 参考: 現在のレシピデータの傾向

- 中スパイク〆のセットプレイが 7件と中心。起き攻めの派生（シミー可否、KK派生、中段、DI 重ね）を網羅する使い方
- ダメージ入力があるのはコンボ系 3件のみ。セットプレイは 0（未入力）
- Dゲージ消費が入っているのは 1件のみ
- メモにフレームデータ（+5F、+52F、-26F 等）や計算式が頻出 → 構造化する価値が高い
