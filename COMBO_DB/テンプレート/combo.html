キャラ名COMBO

名前は見出し・タブ名・習得状況の保存キーに使います
（なし） 45%

動画をここにドロップ、またはクリックして選択

使い方
  1. 「編集」→ 編集バーの「キャラ名」を入力し、「背景画像」を好みで設定する。キャラ名はポータルに登録した名前と同じにする（習得状況の表示に使う）
  2. 録画した動画は compress.bat にドラッグ&ドロップすると clips/ に軽量化される（ffmpeg.exe は スト６/ 直下に1つ置く）
  3. 「作業フォルダを接続」でこのフォルダ（COMBO_DB/<キャラ名>/）を選ぶと、動画の書き込みと再生ができる
  4. 「レシピを追加」→ クリップ名・レシピ（半角スペース区切り。色分けは下記の規則）・ダメージ・Dゲージ・SA・タグ・メモを入力し、動画をドロップか「接続フォルダ内の動画から選ぶ」
  5. カードの ☆ でお気に入り、「未習得」で習得済みを切り替え。上部のチップで絞り込み、「並び順」で並べ替え
  6. 変更したら「HTMLを保存」で combo.html を上書きする。「配布用HTMLを書き出す」は動画を埋め込んだ1ファイルを作る

背景画像の選び方（コンボDB）

  • このキャラのキーアートや公式イラストが向く。置き場所は 画像/<キャラ名>/（キャラ名はこの画面で設定した名前と同じ英字）
  • 動画カードが左、レシピが右に並ぶので、キャラが右側にある画像だと動画に隠れにくい
  • 大きさ: 横長（16:9 前後）で、幅 1920px 以上が目安（最低でも画面幅の 1280px）。画面いっぱいに拡大して敷かれるため、小さい画像はぼやける
  • 明るさ: 明るめで淡い画像が向く。紙色の上に「乗算」で重ねるので、白い部分は紙色のまま、暗い部分だけが沈む。暗い画像は 45% でも重く見えるので濃さを下げる
  • 構図: 被写体（キャラ）が中央〜右にある画像。左上に見出し、左側にカードや動画が並ぶので、左に顔があると隠れる
  • 避けるもの: 文字やロゴが大きく入った画像（見出しと重なる）、細かい模様（グレースケールにすると濁る）、縦長の画像（左右が切れる）
  • 濃さ: 色ありなら 30〜45%、グレースケールなら 20〜35% が目安。カードの上の文字は影響を受けないので、雰囲気と背景の見やすさで決める
  • 形式: JPG（写真・アート）か PNG。1枚 2MB 以内にしておくと開くのが速い

レシピの色分け規則（半角スペースで区切った各トークンに自動で色が付く）

  • DR / CDR / Dゲージ: ドライブラッシュ、キャンセルドライブラッシュ、Dゲージの塗り R0 G199 B166
  • DI: ドライブインパクト R197 G68 B94
  • コマンド技: 214MK 236HK 623P [4]6P のように数字コマンドで始まるもの R45 G29 B165
  • SA1 / SA2 / SA3 / CA（236236P などの SA コマンドも同じ） R224 G120 B0
  • それ以外（通常技、技名、PC / CH など）は黒

クリップの再生: クリックで再生 / 停止、◀ ▶ で 1/20 秒ずつコマ送り。動画にフォーカスがあるときは ← → キーでも動く。タグの種類は HTML 内の TAG_ORDER、色は :root の --dr --di --cmd --sa で変えられる。
