# テンプレート — 新しいキャラのフォルダを作る手順

このフォルダは新キャラ用の雛形です。**このフォルダ自体は編集せず**、コピーして使ってください。

## 1. フォルダをコピーする

```
スト６/
├── ffmpeg.exe             ← 全ツール共用（ここに1つ置く）
├── index.html             ← ポータル（キャラ一覧・リンク集）
├── COMBO_DB/
│   ├── テンプレート/      ← 雛形（触らない）
│   ├── ラシード/
│   └── ケン/              ← テンプレート をコピーしてキャラ名に変更
│       ├── combo.html
│       ├── compress.bat
│       ├── clips/
│       └── README.md      ← 消してよい
└── VS_DB/            ← 相手キャラ対策（VS_DB/テンプレート/ をコピーして作る）
```

## 2. キャラ名を設定する

1. `combo.html` を Chrome / Edge で開く
2. 右上の「編集」→ 編集バーの「キャラ名」にキャラ名を入力
3. 「HTMLを保存」で `combo.html` に上書き

キャラ名は見出し、タブのタイトル、習得状況の保存キー（`localStorage`）に使われます。

## 2b. ポータルに登録する

`スト６/index.html` を開き、「編集」→「キャラを追加」。キャラ名は combo.html に設定したものと**同じ**にする（習得状況の表示に使う）。フォルダ名が違う場合だけ「フォルダ名」欄に入れる。
自分が使うキャラは「自キャラ」にチェック（上の枠に大きく表示）。画像は `スト６/画像/<キャラ名>/` に置き、「画像を選ぶ」でそのファイルを選ぶ。選んだ画像はカード全面に敷かれるので、横長のキーアートが向く。

## 3. ffmpeg.exe の置き場所

`compress.bat` は次の順で `ffmpeg.exe` を探します。

1. キャラフォルダ内（`COMBO_DB/ケン/ffmpeg.exe`）
2. ひとつ上（`COMBO_DB/ffmpeg.exe`）
3. ふたつ上（`スト６/ffmpeg.exe`）← **標準の置き場所。ここに1つあれば全ツールで共用**（約100MB）
4. PATH

## 4. 動画の追加

1. 録画した動画を `compress.bat` にドラッグ&ドロップ → `clips/` に軽量化された mp4 ができる
2. `combo.html` の「編集」→「作業フォルダを接続」でキャラフォルダを選ぶ
3. 「レシピを追加」→ 動画をドロップ、または「接続フォルダ内の動画から選ぶ」

コマ送りは 1/20 秒単位です。`compress.bat` の `FPS=20` と `combo.html` の `FPS = 20` は揃えてください。

## 4b. 背景画像

「編集」→ 編集バーの「背景画像: 画像を選ぶ」で `画像/<キャラ名>/` に置いた画像を選ぶと、画面に固定された背景になる（スクロールしても動かない）。「濃さ」と「グレースケール」で調整し、「HTMLを保存」で確定。

## 5. タグを変えたいとき

`combo.html` 内の `TAG_ORDER` と `TAG_COLOR`（`/* タグの定義はここが唯一の場所 */` のコメント直下）を編集します。HTML 側に手書きする場所はありません。
