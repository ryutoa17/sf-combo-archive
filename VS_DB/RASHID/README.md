# キャラ対策 テンプレート — 新しい相手キャラのフォルダを作る手順

このフォルダは相手キャラ対策用の雛形です。**このフォルダ自体は編集せず**、コピーして使ってください。

```
スト６/
├── ffmpeg.exe             ← 全ツール共用（ここに1つ置く）
├── index.html             ← ポータル
├── COMBO_DB/<自キャラ>/  ← 自分が何をするか
└── VS_DB/
    ├── テンプレート/      ← 雛形（触らない）
    └── ケン/              ← テンプレート をコピーして相手キャラ名に変更
        ├── matchup.html   ← ケンにどう対処するか
        ├── compress.bat
        ├── clips/
        └── README.md      ← 消してよい
```

## 1. フォルダをコピーして相手キャラ名にする

`VS_DB/テンプレート/` をコピーし、`VS_DB/<相手キャラ名>/` にする。ポータルのフォルダ名と同じにすること（ポータルの「キャラ対策」ボタンが `VS_DB/<フォルダ名>/matchup.html` を開く）。

## 2. 相手キャラ名を設定する

1. `matchup.html` を Chrome / Edge で開く
2. 「編集」→ 編集バーの「相手キャラ名」に入力
3. 「HTMLを保存」で `matchup.html` に上書き

相手キャラ名は見出しとタブのタイトルに使われます。

## 4. 対策を追加する

「対策を追加」で1件 = 相手の行動1つ。項目:

| 項目 | 必須 | 内容 |
|---|---|---|
| 攻略タイトル | ○ | 例: 対ラシードのサイクロン対策 |
| キャラ | ○ | 「全キャラ共通」か、その対策を使う自キャラ名（ケン、ラシード など）。一度入力した名前は候補に出る |
| クリップ名 | | 動画のファイル名（拡張子なし）。動画なしでも登録できる |
| 補足 | | 自由記述 |
| 参考URL | | 動画や資料へのリンク |

一覧上部の「キャラ」フィルタで絞り込める。自キャラ名を選ぶと、そのキャラの対策と「全キャラ共通」の対策が表示される。

動画はコンボ記録と同じ: `compress.bat` にドラッグ&ドロップ → `clips/` に軽量化 → 「作業フォルダを接続」→ フォームでドロップか「接続フォルダ内の動画から選ぶ」。

## 4b. 背景画像

「編集」→ 編集バーの「背景画像: 画像を選ぶ」で `画像/<相手キャラ名>/` に置いた画像を選ぶと、画面に固定された背景になる。「濃さ」と「グレースケール」で調整し、「HTMLを保存」で確定。

## 5. 「全キャラ共通」の表記を変えたいとき

`matchup.html` 内の `COMMON`（`/* どの自キャラでも通用する対策に付けるキャラ名 */` の直下）を編集する。既存データの値も合わせて直すこと。
